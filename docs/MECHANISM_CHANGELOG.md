# Mechanism codebook history

## Version 1.1 - November 5, 2026

Ryan Yu authorized a seventh mechanism, Non-use equipment/cord-related falls, to distinguish explicitly non-use obstacle/accessory/landing injuries from on/from-surface falls. The Fall definition now explicitly includes supporting-surface use of an unpowered treadmill. The category does not prove a motor was off, nor does absent use context prove non-use. Four conditional mappings remain pending a material definition/context decision. Their inclusion decisions are approved; no production release is claimed.

The earliest initiating event still governs. Actual unmounted moving/servicing, mounting/dismounting and initiating moving-belt events retain their specific rules. Struck by equipment still excludes impacts solely following a fall. Unknown cannot hide a known uncovered event or unfinished review. No automatic classifier is introduced.

All 188 narratives were reassessed. No definite recoding requirement was found for the 171 previously approved decisions; their approvals and original AI/source cells were preserved. The private workbook records explicit new user decisions separately from original AI proposals. The inclusion policy fingerprint and original one-shot prompt stay unchanged; this versioned taxonomy authorization supersedes the old mechanism-version reference only.

Implementation binds version 1.1 and exact canonical definitions in preparation, transfer, loader and sidebar. Loader additionally verifies the actual codebook fingerprint. Filters, charts and exports already use data-driven labels; new tests cover the seventh category, fingerprints, precedence and continued approval gates. Candidate and source records are never rewritten by the migration.
