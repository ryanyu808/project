# Reviewed runtime cohort

The production treadmill_2025.csv and matching provenance contain 109 genuinely approved 2025 ED visits from 188 screened candidates (79 excluded), codebook 1.2. One row is one visit. The original 25 fields and narratives are preserved with eligibility/derived fields. Age 65-120, product 3277 in any product field, literal treadmill mention and the separately accepted injury-focused policy define this subset. The full annual source is 410,201 rows and 25 columns, not the runtime cohort.

Only this README, mechanism-codebook.md, treadmill_2025.csv and treadmill_2025.provenance.json may be published from this directory. The actual finalizer also creates human_approved.reviews.csv, finalization.quality.json and validation.json; these and all candidate/source/review workbooks are private, ignored and excluded from submission. Preserve the original blank review template/source evidence. Provenance binds source, codebook, workbook, review, lookup and policy fingerprints without publishing reviewer notes or personal source paths.

See ../../validation/REAL_DATA_RESULTS.md for exact independently checked weights, severe outcomes, diagnosis composition, filters and CSV reconciliation. These are verified local production values; public-browser verification is a separate release gate.
